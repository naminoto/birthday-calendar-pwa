# 開発専用：7候補のフォント比較

**正式採用後の差分（2026-10-21）**：「現在」は標準Zen Maru Gothicへ戻ります。通常distには採用した400/500/700とOFL・METADATA・SOURCEだけが追加され、全16ファイルです。不採用5書体と比較UI・コードは引き続き入りません。下記の「従来10ファイル」「通常distは増えない」「現在＝OS書体」は採用前の検証記録です。現在の仕様は[正式採用記録](zen-maru-adoption.md)を優先します。比較時もボタン／ホーム見出しは全候補500へ統一し、比較用FontFaceの解放では標準CSSの3Faceを残します。比較ビルドは正式採用の11.42MBも含むため、フォント本体は一時的に合計約65.76MBになります（本番には11.42MBだけ）。

Version 1.4.1・現在のホームレイアウトを維持し、文字サイズ・指定ウェイト・余白・色を変えずフォントfamilyだけ切り替えます。実行時の外部フォント通信はありません。フォント選択はメモリ内だけで、IndexedDB・localStorage・ZIP・通知設定へ保存しません。再読み込みすると「現在」に戻ります。

先に[ライセンス事前調査](font-license-review.md)を確認してください。取得済みファイルの完全なURL・取得日時・各ファイルのSHA-256・内部Version・著作権原文は`dev/font-lab/inventory.json`、各書体の`OFL.txt`と`METADATA.pb`は`dev/font-lab/fonts/<id>/`にあります。6書体とも導入可、保留なしです。Noto Sans JPのRFNはSource、LINEの商用帰属表示は強く推奨です。Noto Serif JPは配布OFLのGoogle表示と内部メタデータのAdobe表示を両方保持します。

## 使い方

### 通常の開発サーバー（フォント比較は明示指定時のみ）

```powershell
npm run dev -- --mode font-lab --host 127.0.0.1 --port 5190 --strictPort
```

`http://127.0.0.1:5190/`を開き、画面下の「Aa フォント比較 / 開発専用」を展開します。「現在のフォント」と6書体を選べます。読込成功後に切り替え、失敗時は前の書体を保持します。ホーム・カレンダー・人物・誕生日・設定・追加／編集フォームに適用し、比較パネル自体はシステムフォントのままです。旧Faceは切替時に解除し、元に戻すと比較CSSを無効にします。アプリ本来の通知・設定とは別の開発コントロールです。

普段の`npm run dev`には比較UIが出ません。通常の開発版はService Workerを登録しないため、**開発サーバーを切った後のオフライン再起動は保証しません**。選択済みフォントはメモリ上で表示できますが、完全なオフライン確認には次の専用比較版を使ってください。

### 完全オフライン対応の比較専用プレビュー（推奨）

```powershell
node scripts/build-font-lab.mjs
node scripts/serve-font-lab.mjs
```

`http://127.0.0.1:5191/font-lab/`を開きます。初回は約54MBのフォントを含むシェルのキャッシュ完了を待ちます。その後はサーバー／ネットワーク停止中も再起動・全6書体への切り替えができます。**このビルドは開発用で、絶対に公開しないでください。**

- 出力はGit除外の`test-artifacts/font-lab/`のみ。通常の`dist/`は上書きしません。
- 既存SWテンプレートをそのまま使い、この専用`/font-lab/` scopeに属する旧キャッシュだけを清掃します。IndexedDBは削除しません。フォントとライセンスはシェルキャッシュ、人物・画像は従来のIndexedDBで分離します。
- 専用ポート5191は本番Pagesや通常開発5173とは別originなのでデータを混在させません。**同じホストのサブパスだけではIndexedDBの分離にならない**ため、ポートを流用しないでください。既存PWAのURL・scope・DB名は変更していません。
- 比較画面は最初は空です。架空の人物を手動登録するか、必要なら元端末のZIPをコピーしてこの比較環境へ手動復元できます。元の本番データには影響しません。実データを含むZIPやスクリーンショットをGitへ入れないでください。
- 選択状態の保存、データの自動投入、定期キャッシュの増殖はありません。保持するアプリキャッシュは当該scopeの最新1世代だけです。ブラウザ独自のHTTPキャッシュ・OSのフォントキャッシュは別管理で、アプリから無理に削除しません。
- 端末の空き容量やブラウザのデータ退避・削除により、オフラインキャッシュの維持は保証されません。人物データは従来どおりZIPで退避してください。

## 容量・ウェイト・Version

TTFは改変・変換・サブセット化していません。必要な静的400/500/700だけを選び、LINEは500を配布していないため400/700です。可変Notoはそれぞれ1ファイルで、ウェイト別に複製しません。

| 書体 | フォント本体 bytes（10進MB） | 導入ウェイト | 内部Version |
| --- | ---: | --- | --- |
| LINE Seed JP | 7,459,424 (7.46MB) | 400 / 700 | Regular 1.003、Bold 1.010 |
| Zen Kaku Gothic New | 7,002,848 (7.00MB) | 400 / 500 / 700 | すべて1.002 |
| Noto Sans JP | 9,589,900 (9.59MB) | variable 100–900 | 2.004-H2 |
| M PLUS 1p | 5,284,148 (5.28MB) | 400 / 500 / 700 | すべて1.062 |
| Zen Maru Gothic | 11,422,752 (11.42MB) | 400 / 500 / 700 | Regular 1.002、Medium/Bold 1.001 |
| Noto Serif JP | 13,574,352 (13.57MB) | variable 200–900 | 2.003-H1 |

比較用原本は合計13ファイル、54,333,424 bytes（54.33MB、約51.82MiB）。正式採用後の比較専用ビルドには標準Zen Maru Gothicの別URLの3本も入り、フォント本体は約65.76MBです。通常distには標準3本の約11.42MBだけが入ります。権利文書とシェルは別途少量加わります。比較原本・公開用コピー・両ビルドを同時に置く開発ディスクや、デコード後メモリはこれ以上を必要とします。これは一時的な比較用途で、本番には6書体を配信しません。静的書体にないウェイトはブラウザの通常マッチング／合成、絵文字・未収録文字は端末フォールバックです。

採用前はCSSの `Inter,"Hiragino Sans","Yu Gothic",Meiryo,system-ui,sans-serif`で、Windows Edgeの日本語・英数字サンプルはYu Gothic、絵文字はSegoe UI Emojiでした。現在の標準はZen Maru Gothic＋端末フォールバックです。「現在」に戻した後の実描画もZen Maru GothicとSegoe UI Emojiで再確認しました。iPhoneの端末フォールバックは異なり得ます。OSフォント本体を抽出・同梱しているわけではありません。

## 取得・検証と比較画像

フォントを再取得する場合は、固定commitとライセンス記録を確認してから`node scripts/acquire-dev-fonts.mjs`を明示的に実行します。自動起動やアプリ内のダウンロード処理はありません。固定元は事前調査とcatalogの両方に記録し、取得した全TTF・OFL・METADATAのSHA-256をテストします。ファイルの更新・版の混在を独断で補正せず原配布物を保持します。

```powershell
npm test
npm run build
node scripts/browser-smoke.mjs
# 専用プレビューを別ターミナルで起動してから実行
node scripts/release-smoke.mjs --url=http://127.0.0.1:5191/font-lab/ --check-font-lab=true
```

フォント検証は実利用者とは分離した一時Edgeプロファイルと架空データを使用します。同じ2027/5/10（東京）・日本語・ライト・390×844px・スクロール0の7枚を`test-artifacts/font-comparison/`へ保存し、`index.html`に並べます。`report.json`に実描画フォントと条件を記録します。全5タブ・日英・ライト／ダーク・320/390/430/768/1280px、モバイル入力16px、オフライン再起動・全書体切替、4 storeと画像の不変を確認します。日本語・英数字・記号の実グリフもTTFのcmapで検証します。

## 本番への混入防止

- `vite.config.js`は**modeがfont-labのときだけ**開発用プラグインを読み込みます。通常のproductionや通常devは無効です。`src/app.js`に比較コードをimportしていません。
- 比較原本は`dev/font-lab/fonts/`のままです。正式採用だけを`public/fonts/zen-maru-gothic/`に無改変コピーし、通常成果物は16ファイル（標準TTF3本・OFL・METADATA・SOURCEを含む）です。`audit-dist.mjs`は標準書体の原本一致を確認し、不採用5書体・比較識別子・許可外ファイルを拒否します。
- 比較専用ビルドは別スクリプトだけが作り、GitHub Actionsの既存公開対象は`dist/`のままです。比較ビルドをdistへコピーしたり公開Workflowの対象に指定しないでください。
- Zen Maru Gothic正式採用のローカル実装・自動検証は別記録へまとめています。公開操作は行わず、iPhone／Android実機の確認はユーザーが行います。

## iPhoneで後から確認する項目

Windows Edgeのタッチ幅テストはiOS WebKit実機の代わりではありません。7候補の日本語・英数字・絵文字・入力欄フォーカス、長い人物名、省略／折返し、日付、残日数、ライト／ダーク、切替時の待ち時間とメモリを確認してください。LAN上でViteを使う場合は明示的に`--host 0.0.0.0`へ変更し、信頼するLANに限定します（こちらではLAN公開やFirewall変更を行っていません）。HTTPのLAN URLではService Workerを利用できないため、iPhoneでオフライン再起動を検証するには信頼できるHTTPSのローカル配信環境が別途必要です。公開URLや実PWAのscopeを変更して比較版を載せないでください。既存iPhoneアプリの削除・再追加・サイトデータ削除は不要です。
